# Project images

Project card images are referenced explicitly in `src/data/content.ts` through
`asset(...)`, so adding or replacing an image means updating the matching
project entry there.

Served assets live under `public/assets/`. The paths below are relative to
`public/assets/projects/`.

| File                                          | Shown in                      |
| --------------------------------------------- | ----------------------------- |
| `../images/projectImages/ceylonpathways.webp` | Ceylon Pathways feature card  |
| `telca-cctv.jpg`                              | Telca Solutions CCTV card     |
| `nethwin-bookshop.jpg`                        | Nethwin Bookshop card         |
| `ps-portfolio.jpg`                            | Campus Portfolio card         |
| `eternal-essence.webp`                        | Eternal Essence Weddings card |

Recommended: about 1600 px wide, 16:9 aspect ratio, WebP or JPG, under 300 KB
where practical.
